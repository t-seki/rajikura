rajikura

聴きたいラジオ番組を、自分のライブラリに。

番組表から予約したラジオ番組を毎週録音して、自分のライブラリにまとめます。

入れ方を見る動かせる条件を確かめる

番組を予約すれば、毎週勝手に録ります

番組表から番組を予約すると、放送のたびに自動で録音して、ライブラリに保存します。

PC をつけっぱなしにしなくて大丈夫

rajikura を起動したときに、録音期限の内側なら、録り逃した放送を取り直します。Windows のサービスとしてインストールしていれば、PC の起動と一緒に立ち上がります。毎週の予約なら、放送の前の 7 日のうちに一度は起動していることが条件です。

あとから聴けない放送も、ライブで録れます

タイムフリーの対象外の放送は、放送中にライブで録ります。放送の時刻に rajikura が動いている必要があり、録り逃したら後から取り直せません。

分割番組を 1 つのファイルに
分割して放送される番組は、パートをつないで 1 つのファイルにできます。
チャプター・カバー画像・タグ
録ったファイルに、チャプター・カバー画像・タグが入ります。チャプターはタイムフリーから録ったときだけで、チャプターに飛べるかはプレイヤーによります。
Jellyfin・kikidame で聴けます
Jellyfin や、Android アプリの kikidame で聴けます。
Windows・Linux・コンテナ
Windows（x64）と Linux（x64・arm64）で動き、コンテナ（x64）でも動かせます。入れ方へ
無料・広告無し
無料で、広告もありません。MIT ライセンスの OSS です。

動かせる条件

  • 日本の、自分の radiko のエリアの回線から使います。
  • radiko の会員種別は、非会員・エリアフリー・タイムフリー30・ダブルプランの 4 つです。非会員でなければ、radiko のアカウントのメールアドレスとパスワードが要ります。
  • radiko のログインは、ダブルプランのアカウントで動くことを確かめています。ほかの会員種別（タイムフリー30 単体など）では確かめていません。
  • serve は LAN や VPN の内側で使ってください。インターネットに出さないでください。

利用範囲

  • 個人の私的利用に限ってください。録音した音声データを共有・再配布しないでください。
  • radiko・NHK とは関係のない、非公式の道具です。
  • radiko の利用規約を自分で読み、自分の責任で使ってください。
  • エリアを偽装しないでください。エリアの外の局は、エリアフリー会員の正規の radiko のログインでだけ録ってください。
  • radiko の仕様が変わると録れなくなることがあり、直す時期は約束しません。

入れ方

  • はじめに入れ方の選び方と、初めて入れるときの手順。
  • Windows のサービスとして入れるWindows で常に動かす入れ方。
  • GitHub Release の最新実行ファイルの入手先。
