rajikura

radiko の番組を毎週自動で録って、ライブラリに保存する。

入れ方

  • はじめに: 入れ方の選び方と、初めて入れるときの手順。
  • Windows のサービスとして入れる: Windows で常に動かす入れ方。
  • GitHub Release の最新: 実行ファイルの入手先。

利用範囲

  • 個人の私的利用に限る。録音した音声データを共有・再配布しない。
  • radiko・NHK とは関係のない、非公式の道具である。
  • 使う人は radiko の利用規約を自分で読み、自分の責任で使う。
  • エリアを偽装しない。エリアの外の局は、エリアフリー会員の正規の radiko のログインでだけ録る。
  • radiko の仕様が変わると録れなくなることがあり、直す時期は約束しない。
