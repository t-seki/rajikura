# 放送回の番組名が番組の名前と違えば title に足す

## 決定

保存するファイルの `title` のタグは、放送回の番組名が番組の名前（`name`）と同じなら `YYYY-MM-DD`、違えば `YYYY-MM-DD 放送回の番組名` にする。アルバム（`album`）は `name` のまま 1 つで、放送回の番組名でアルバムを分けない。

- 同じかどうかは、両方から番組名の末尾の印を落とし、正規化（全角 → 半角、空白を除く、大文字にそろえる）したうえでの完全一致で決める。番組名の食い違い（前方一致）とは比べ方が違う。
- 足す番組名は原文どおり（全角空白・全角記号も残す）で、番組名の末尾の印だけを落とす。
- パートがあれば `YYYY-MM-DD (N) 放送回の番組名`。
- 連結したジョブは放送回ごとに判断し、`name` と違う放送回の番組名を、重複を除いて開始時刻の順に ` / ` でつなぐ。
- 判断は放送回ごとに自動で行い、番組ごとの設定は作らない。

例（`name` は `サンプルナイトラジオ0`）:

| 放送回の番組名 | title |
| --- | --- |
| `サンプルナイトラジオ0　特別編～夜の会議～` | `2026-10-17 サンプルナイトラジオ0　特別編～夜の会議～` |
| `○○のサンプルナイトラジオ0` | `2026-10-24 ○○のサンプルナイトラジオ0` |
| `サンプルナイトラジオ0` | `2026-10-31` |

分割番組（`サンプル朝の情報便 (1)` と `(2)`、`name` は `サンプル朝の情報便`）は、末尾の印を落とすと `name` と同じなので、title は `YYYY-MM-DD` のまま。

## 理由

- 週ごとに副題や出演者の名前が番組名に入る番組がある。番組の名前からは回ごとの副題を落とす（[ADR 0006](0006-show-name-from-radiko.md)）ので、どこかに残さないと、放送回の番組名がどのタグにも残らない。
- 前方一致で比べると、`サンプルナイトラジオ0 feat. …` のような回が `name` と同じと判断され、副題が残らない。
- 番組名が変わらない番組は、`YYYY-MM-DD` だけの方が一覧がすっきりする。
- 放送回ごとに自動で判断すれば、設定を書かずに済み、普段は番組名が変わらない番組に特番の回が入ったときにも、その名前が残る。
- title に入れれば、Jellyfin の曲の一覧でも、タグの title を出すプレイヤーでも見える。日付を先頭に残すので、title だけを出す画面でもどの回か分かる。

## 検討した案

- 全部の番組で title を `YYYY-MM-DD 放送回の番組名` にする。普通の番組では冗長になる。
- `comment` など、表示されにくいタグに入れる。ほとんど見えないので、その回の番組名を残す目的に合わない。
- 番組ごとの設定で、title に番組名を足すかを選ぶ。設定を書く手間が増え、普段は変わらない番組の特番の名前が残らない。
- 放送回の番組名でアルバムを分ける。週ごとに名前の変わる番組は毎週アルバムが分かれ、番組名の小さな違いでも分かれる。出演者ごとに見たいなら、`artist`（出演者）で辿れる。

## 帰結

- 放送回の番組名が週ごとに変わる番組は、番組名の食い違いにも当たり続ける。番組ごとに食い違いを調べない設定（番組の `check_title` をオフ）で外す（[ADR 0019](0019-skip-by-title-and-by-person.md)）。この設定は title の形には関係しない。
- 保存済みのファイルのタグは書き直さない。
