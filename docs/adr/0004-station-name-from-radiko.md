# 保存先の局名は radiko の局名にする

## 決定

保存先の局名（フォルダ名と `album_artist` のタグ）は、radiko の局一覧（`https://radiko.jp/v3/station/list/JP13.xml` など）の局名をそのまま使う。「（東京）」などの末尾も加工しない。radiko の局名が空なら局 ID を使う。局名を変える設定は持たない。

## 理由

- radiko の局名なら、対応表の設定が要らない。
- 局名を加工する規則を持つと、規則と例外が増える。

## 検討した案

- 局 ID から局名への対応表を設定に持つ。設定が増え、局名を決める手間を人に渡すことになる。
- radiko の局名を整える（「（東京）」を外すなど）。加工の規則が増えるので、そのまま使う。

## 帰結

- radiko が局を改称すると、新しい回が別のフォルダに分かれる。前のファイルを新しい名前のフォルダへ移せば揃う。
- 起動してから局一覧が一度も取れていないときだけ、保存先の局名が分からないので待つ。局一覧は取れたが局が載っていない（廃局など）ときと、載っていても局名が空のときは、待たずに局 ID で保存する（載っていないときは Warn を出す）。
- 待つ判断は、入手の後、格納の前（`save` の中で局名を決めるところ）で行う。入手の前に確かめると、最後の試行のときに何も取れずに録音できなかったになり、放送回を失うため。
- 局名が決められずに失敗した試行は、格納・検証の失敗と違って、入手した放送回を捨てない。次の試行は入手した放送回を使い回し、radiko から取り直さない。この失敗も試行回数に数え、ほかの失敗と同じ再試行の間隔と上限に乗せる。
- 録音期限を過ぎても局一覧が取れていないときは、局 ID で保存して録音済みにする（Warn を出す）。録音できなかったにはしない。フォルダが二重になっても、ファイルを移して直せる。
- radiko 以外のソースに対応するときは、局名の決め方を考え直す。
